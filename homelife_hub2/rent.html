📋 계약 시 꼭 확인할 사항

  • 계약 전 등기부등본 열람 — 근저당·가압류 여부 확인 필수
  • 건축물대장 확인으로 불법·위반건축물 여부 파악
  • 임대인이 실제 소유자인지 신분증·등기부등본 대조
  • 전세의 경우 전입신고 + 확정일자는 이사 당일 반드시 진행
  • 전세보증금 반환보증 가입 여부 확인 (HUG·HF·SGI)
  • 특약에 수리 책임, 퇴거 시 원상복구 범위 명확히 기재
  • 묵시적 갱신 시 자동 연장 — 계약 만료 2개월 전까지 의사 표시 필요

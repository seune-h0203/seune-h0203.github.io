레이아웃 개요

메인, 사이드바, 푸터로 구성된 페이지 템플릿을 통해 깔끔하고 정돈된 사이트 구조를 제공합니다.

표준 템플릿

메인 콘텐츠와 좌우 사이드바를 포함하는 안정적인 레이아웃입니다.

모바일 대응

화면 너비가 좁아지면 카드와 사이드바가 세로로 정렬됩니다.

구성 요소

  • 상단 고정 헤더와 드롭다운 네비게이션
  • 중앙 메인 콘텐츠 영역
  • 왼쪽/오른쪽 정보 사이드바
  • 깔끔한 카드, 표, 체크리스트 화면

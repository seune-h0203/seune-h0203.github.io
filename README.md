# NESTRA

생활 밀착형 주거 정보 플랫폼 — 웹디자인 기말 발표 프로젝트

## 사이트 구성
- index.html — 메인 페이지 (히어로 배너 + 핵심 서비스 + 주거 소식 카드)
- moving.html — Moving & Checklist (이사 체크리스트 / 비용)
- layout.html — Layout & SpaceFit (가구 배치 / 공간 활용)
- rent.html — Rent & Market (전월세 시세 / 면적 비교 / 계약 유의사항)
- remodel.html — Remodel & Design (리모델링 비용 / 인테리어 사례)
- safety.html — Safety & Community (안전 점검 / 유지보수 / 후기)
- common.css — 공통 스타일시트
- img/ — 이미지 폴더 (hero.jpg, card-*.jpg)

## 주요 기술
- HTML5 시맨틱 태그 (header, nav, aside, section, footer)
- 12열 가변 그리드 시스템 (.c1 ~ .c12)
- 미디어 쿼리 기반 반응형 웹 (768px 기준 / PC ↔ 모바일)
- 순수 CSS 드롭다운 네비게이션 (position:absolute + hover)
- 히어로 사진(JPG) + SVG 아이콘 + 카드형 레이아웃

## 이미지 경로 규칙
GitHub에서 이미지가 깨지지 않도록 상대경로(`./img/파일명`) 형식을 사용합니다.

## 실행 방법
1. 저장소를 클론하거나 압축을 풉니다.
2. index.html을 브라우저에서 엽니다.
3. (GitHub Pages) Settings → Pages → Branch: main 선택 후 배포.
